FS Platform Model 交接总览（V1.0.3a）

本文档用于 V1.0.3a 交接，重点说明 static/dynamic clearance、effective travel、range 模式 inputs 结构与 warning 机制的正式语义。

本次版本增量

  • 正式拆分 static clearance 与 dynamic clearance
  • rules 层只看静态离地高
  • targets 层只看动态离地高
  • 引入 effective travel 进入 rule check
  • 修正 tire.mode='range' 顶层 results.inputs / inputsRaw / inputsNominal 结构
  • validation.warnings 在 warnOnDeprecatedInput=true 时真实 warning(...) 发射
  • run_batch summary 增加 static/dynamic clearance 与 effective travel 字段

当前统一物理语义

  • kw = ks * mr^2
  • keq = kw（off）
  • keq = kw * kt / (kw + kt)（fixed / range）
  • deltaSuspWheel = Fmain ./ kw
  • deltaTire = Fmain ./ kt
  • deltaGround = deltaSuspWheel + deltaTire
  • shockStroke = mr .* deltaSuspWheel

clearance 定义

  • 静态：results.clearance.hStaticAll / hStaticMin / hStaticMinName
  • 动态：results.clearance.hDynamicAll / hDynamicMin / hDynamicMinName
  • 兼容字段 hAll / hMin / hMinName 统一映射到 dynamic clearance

effective travel

  • effectiveJounce = min(jounceMax, wheelJounceFromShock)
  • effectiveDroop = min(droopMax, wheelDroopFromShock)
  • effectiveTotalTravel = effectiveJounce + effectiveDroop

run_batch 关键列

  • hStaticMin, hDynamicMin, hMin
  • StaticGroundClearancePass, DynamicClearancePass
  • EffectiveJounce, EffectiveTotalTravel
  • RulePass, DesignPass, Feasible
