FS Platform Model 交接总览（V1.0 → V1.0.1 → V1.0.2 → V1.0.3）

本文件用于跨线程交接。建议优先阅读同目录 FS_Platform_Model_Handover_V1.0_to_V1.0.3.md（最完整版本）。

V1.0.3 核心升级

  • 新增 tire.mode = off/fixed/range，支持轮胎柔度模式化。
  • 位移语义拆分为 deltaGround / deltaSuspWheel / deltaTire / shockStroke。
  • 新增赛规层 results.rules 与工程目标层 results.targets。
  • 正式分离判定层：converged / rulePass / designPass / feasible。
  • 气动插值显式输出 clamp/fallback 标志，禁止静默失败。
  • run_batch summary 扩充为可直接筛选方案。

主接口与结构连续性

  • 单入口保持：run_case(caseDef, options)
  • 批处理保持：run_batch(caseArray, options)
  • 目录结构保持：main/config/core/aero/utils/visualization/tests/data

新增输入层

  • caseDef.tire：mode、ktFront/ktRear、ktFrontRange/ktRearRange
  • caseDef.rules：静态离地高、总轮跳、最小 jounce 等赛规约束
  • caseDef.targets：动态离地高、姿态窗口、aero loss、配平迁移窗口

range 模式输出

  • results.range.low
  • results.range.nominal
  • results.range.high
  • results.range.band（区间汇总）

插值可追踪标记

  • mapClampedAny
  • hfClamped / hrClamped / phiClamped / betaClamped
  • interpFallbackUsed
