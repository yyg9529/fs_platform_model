FS Platform Model 交接文档（V1.0.4｜Pre-V1.5 Interface Cleanup）

本文件记录本轮“进入 V1.5 前的接口清洁型修订”。它不是新版本主线文档，而是在当前 V1.0.4 稳定骨架上，对标准 case 与正式接口做一次定点清理。

本次修订的定位

  • 不重建项目，不改主目录结构。
  • 不进入 V1.5 的轮胎代理层开发。
  • 不改写三自由度准静态平台主求解链。
  • 只做标准 case 显式化、sus.kt 正式迁移、warning 清洁。

本次核心结论

  • 标准 case 现在尽量显式给出活跃字段，不再依赖 autofill warning 才成立。
  • 标准轮胎输入正式统一到 tire.mode / ktFront / ktRear / ktFrontRange / ktRearRange。
  • sus.kt 只保留 backward compatibility，不再出现在 baseline / target 正式输入中。
  • baseline / target / demo 正常运行时，不再出现 Auto-filled missing fields 与 caseDef.sus.kt is deprecated warning。
  • shock/wheel consistency warning 机制仍保留，但标准 case 不应长期带着该 warning 运行。

warning 机制的当前定位

  • autofill warning：继续用于暴露输入缺口。
  • deprecated warning：继续用于暴露旧字段残留。
  • shock/wheel consistency warning：继续用于暴露机械约束矛盾。

当前要求： 这些 warning 机制仍保留，但主要服务于旧 case 兼容与异常测试，不应再成为标准 case 的正常运行前提。
