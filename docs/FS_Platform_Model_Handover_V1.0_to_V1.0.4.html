FS Platform Model 交接总览（V1.0.4）

本版本是在 V1.0.3a 基础上的连续升级，不重建项目、不改写 solver 主链，也不进入 V1.5 或 V2.0。

版本链

  • V1.0：建立三自由度准静态平台模型与气动耦合主链。
  • V1.0.1：停用 bump/droop 附加力，引入 eye-to-eye shock 输入与行程后处理判据。
  • V1.0.3a：拆分 static/dynamic clearance，rules 只看静态，targets 只看动态，并引入 effective travel。
  • V1.0.4：新增 spring sweep map 与 bump-adjusted scrape robustness map。

V1.0.4 核心新增

  • 新增 aeroPlatformPass，定义为 aeroLossPass && frontShareMigrationPass。
  • 新增 scrapePassQuasiStatic，定义为 static rule + dynamic clearance target + 无 clearanceViolation。
  • 新增 scrapePassBumpAdjusted，定义为 static rule + bump-adjusted dynamic clearance target + 无 bump-adjusted violation。
  • 新增 caseDef.bumpAdjust.enable/reserveFront/reserveRear/notes。
  • 新增 quasi-static 与 bump-adjusted 两套四色分类编码。

spring sweep 工作流

  • run_spring_sweep(baseCase, sweepDef, options)
  • build_spring_sweep_cases(baseCase, sweepDef)
  • plot_spring_sweep_map(sweepOut, mode, options)
  • demo_spring_sweep_map()

扫参方式是前轴左右同值修改 sus.ks(1:2)，后轴左右同值修改 sus.ks(3:4)。这只是批处理筛选层增强，不是新求解器。

bump-adjusted 语义

本版本 bump 功能只是在准静态 hDynamicAll 上做保守扣减：

  • 前部点减 reserveFront
  • 后部点减 reserveRear
  • 中性点减 max(reserveFront, reserveRear)

新增结果包括 hDynamicAllBumpAdjusted、hDynamicMinBumpAdjusted、dynamicClearanceBumpAdjustedPass 与 bumpAdjustedClearanceViolation。

物理边界： 这不是完整瞬态 bump 模型，不新增自由度、不解时域动力学、不包含 tire load sensitivity 或 bicycle transient。

map class code

  • 0 = All Cases Fail
  • 1 = Only Aero Passes
  • 2 = Only Scrape Passes
  • 3 = Both Cases Pass
