版本演进

  1. V1.0：建立三自由度准静态平台模型与气动耦合主链。
  2. V1.0.1：停用 bump/droop 附加力；引入 shock eye-to-eye 输入与后处理约束。
  3. V1.0.2：统一为悬架-气动平台模型，主平衡刚度改为 keq=kw，kt 不再参与主平衡。

V1.0.2 核心定义

  • 状态：q=[z;theta;phi]
  • 符号：z>0 下沉，theta>0 车头下俯，phi>0 向右侧倾
  • kw = ks * mr^2，且 keq = kw
  • 禁止继续使用：keq = kw*kt/(kw+kt)
  • deltaWheel = 纯悬架轮端位移
  • shockStroke = mr .* deltaWheel

converged 与 feasible

  • sus.kBump/bumpGap/kDroop/droopGap：兼容保留，当前忽略
